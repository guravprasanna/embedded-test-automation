#### Day 04 Project — Device Value Converter
Built a menu-driven Python CLI for converting:

- Voltage: V ↔ mV
- Current: A ↔ mA
- Resistance: kΩ ↔ Ω
- Power: kW ↔ W

The project uses functions, conditional logic, loops, user input and calculations.
